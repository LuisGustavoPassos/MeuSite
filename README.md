Portfólio pessoal para apresentar minha trajetória em Engenharia de Software, experiências, projetos e formas de contato.

> **Status:** planejamento visual definido; implementação do site ainda não iniciada.

## Objetivos

- Apresentar meu perfil como Engenheiro de Software e desenvolvedor fullstack.
- Reunir experiências e projetos com contexto e informações verificáveis.
- Disponibilizar o conteúdo em português e inglês.
- Oferecer tema claro e escuro.
- Manter uma interface responsiva e consistente com o sistema visual definido.

## Estrutura prevista

1. **Apresentação** — resumo profissional e contexto atual.
2. **Experiência** — histórico profissional.
3. **Elsewhere** — links para perfis profissionais externos, como GitHub e LinkedIn, caso sejam incluídos.
4. **Projetos** — trabalhos selecionados com descrição e links.
5. **Contato** — e-mail ou outro canal público definido.

## Sistema visual

A direção visual usa Space Grotesk como tipografia principal e a paleta:

| Cor | Código |
|---|---|
| Navy | `#2F4156` |
| Teal | `#567C8D` |
| Sky Blue | `#C8D9E6` |
| Beige | `#F5EFEB` |
| White | `#FFFFFF` |

As cores têm papéis semânticos definidos para os temas claro e escuro. A estrutura de conteúdo toma como referência [wojtek.im](https://wojtek.im/), sem buscar uma cópia visual exata.

## Perfil e tecnologias

Sou estudante de Engenharia de Software no 7º período e desenvolvedor fullstack, com atuação no ecossistema .NET e TypeScript/React. Tenho experiência prática em arquitetura, planejamento e refatoração de plataformas legadas, modelagem relacional e criação de componentes reutilizáveis.

Tecnologias declaradas no meu perfil:

- **Frontend:** HTML5, CSS3, JavaScript, TypeScript, React, Tailwind CSS e Vite.
- **Backend:** C#, .NET Core, ASP.NET Core e Node.js.
- **Bancos de dados:** PostgreSQL, MySQL e SQL Server.
- **Ferramentas:** Git, GitHub, Visual Studio e VS Code.

Esta lista descreve meu perfil; não representa necessariamente a stack escolhida para implementar o portfólio.


## Stack do projeto

- **Interface:** HTML5, CSS3, JavaScript, TypeScript e React.
- **Estilos:** Tailwind CSS.
- **Ferramenta de desenvolvimento e build:** Vite.
- **Backend:** Node.js somente se os requisitos do site vierem a precisar de um servidor.
- **Banco de dados:** PostgreSQL somente se um backend e persistência própria forem necessários. A expectativa atual é não precisar de banco de dados.

Instruções de instalação, execução e build serão adicionadas quando a estrutura do repositório for criada.
